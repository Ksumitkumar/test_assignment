# Hotel Booking & Dashboard App

A pixel-perfect Flutter application built as a technical assignment. Features a custom dark-mode theme with radial cyan background gradients, animated circular floating navigation bar, interactive calendar view, and declarative routing via GoRouter.

---
## Deliverables Summary

* **Complete Flutter Source Code**: Modularized UI architecture, static data extracted into `AppMockData`, and Inter typography using `google_fonts`.
* **Git Repository**: Clean commit history hosted on GitHub with a production-ready project layout.
* **Android Release APK**: Built without debug flags (`app-release.apk`) located in `build/app/outputs/flutter-apk/`.
* **README Documentation**: Comprehensive documentation covering setup commands, build instructions, third-party packages, and technical assumptions.
* **Navigation & UI Implementation**: Pixel-perfect dark theme with cyan radial gradients, interactive 35-day booking calendar grid, and persistent tab bar state managed via `GoRouter`.

##  Requirements

* **Flutter SDK**: `>=3.16.0` (Dart `3.2.0` or higher)
* **Target Platforms**: Android, iOS
* **IDE**: VS Code / Android Studio
